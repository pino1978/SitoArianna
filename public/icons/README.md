# Arianna Milano brand icons

Canonical icon system for the public site.

- `favicon.ico`: multi-size browser favicon (16/32/48/64)
- `apple-touch-icon.png`: 180x180
- `icon-192.png`: 192x192
- `icon-512.png`: 512x512
- `favicon.svg`: lightweight fallback

Approved direction: gold eagle symbol with restrained red eye on deep black. No Chinese ideogram, no circle, no text at favicon size.
